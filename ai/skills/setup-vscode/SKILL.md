# setup-vscode

**Purpose:**
Configures a VS Code project with recommended extensions, editor settings, tasks, launch configuration, and a standard .editorconfig for consistent formatting and developer experience.

## What this skill does
- Adds a `.editorconfig` for consistent code style
- Sets up `.vscode/extensions.json` with recommended extensions
- Configures `.vscode/settings.json` for formatting, spell checking, and file exclusions
- Provides `.vscode/tasks.json` for common npm scripts (build, lint, format, test, coverage, clean)
- Provides `.vscode/launch.json` for Node.js debugging

## How to use
1. Copy the files from `assets/` to your project root:
   - `.editorconfig`
   - `.vscode/extensions.json`
   - `.vscode/settings.json`
   - `.vscode/tasks.json`
   - `.vscode/launch.json`
2. Adjust settings as needed for your project.

## Templates
- See the `assets/` folder for ready-to-use templates.

---

This skill is independent and does not reference any external project. All templates are self-contained.
